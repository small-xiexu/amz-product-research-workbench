# 报告看板化改造说明

## 📋 改造概述

将选品分析报告从传统的**线性滚动式**升级为**看板式交互导航**，数据完全一样，只改变展示方式和用户体验。

**改造日期**：2026-07-01  
**改造文件**：
- `report_template.css` - 增加看板导航样式（约50行CSS）
- `report_agent.py` - 增加看板生成逻辑（约80行Python）

---

## 🎯 核心改进

### 1. **交互式导航**
- ✅ 6个标签页：类目全景、核心竞品、用户痛点、价格带、关键词流量、风险与下一步
- ✅ 粘性导航条（sticky），始终可见
- ✅ Hero区域始终显示在导航条上方
- ✅ 点击标签切换内容，平滑过渡动画

### 2. **键盘支持**
- ✅ 左右方向键切换标签页
- ✅ Tab键焦点管理
- ✅ ARIA无障碍属性完整

### 3. **URL锚点同步**
- ✅ 切换标签自动更新URL（`#pg-category`）
- ✅ 刷新页面恢复上次查看的标签
- ✅ 可直接分享特定章节链接

### 4. **响应式设计**
- ✅ 桌面端：水平标签布局
- ✅ 移动端：横向滚动标签
- ✅ 打印时：自动显示所有页面，隐藏导航

## 🎨 设计原则

### 1. **数据完全一致**
- 看板版和传统版读取同一个 `report_data.json`
- 使用完全相同的 section 构建函数
- 只改变 HTML 结构包裹方式，不修改数据逻辑

### 2. **向后兼容**
- `enable_dashboard=False` 可回退到传统模式
- CSS 向后兼容，传统版依然正常渲染
- 不影响现有的报告生成流程

### 3. **渐进增强**
- JavaScript 禁用时，默认显示第一个标签页
- 打印时自动展开所有内容
- 移动端自动适配横向滚动

## 📐 技术架构

### HTML 结构

```html
<div class="page">
  <!-- Hero：始终可见 -->
  <section class="hero">...</section>
  
  <!-- 看板导航：粘性定位 -->
  <nav class="dash-nav">
    <button class="dash-tab active" data-target="pg-category">①类目全景</button>
    <button class="dash-tab" data-target="pg-competitor">②核心竞品</button>
    <!-- ... -->
  </nav>
  
  <!-- 分页内容 -->
  <main class="dash-main">
    <div class="dash-page active" id="pg-category">
      <section class="section">类目全景内容</section>
    </div>
    <div class="dash-page" id="pg-competitor">
      <section class="section">核心竞品内容</section>
    </div>
    <!-- ... -->
  </main>
</div>

<!-- JavaScript 交互逻辑 -->
<script>
  // 标签切换、键盘导航、URL同步
</script>
```

### CSS 关键类

| 类名 | 用途 |
|---|---|
| `.dash-nav` | 导航容器，粘性定位 + 毛玻璃背景 |
| `.dash-tab` | 导航标签按钮 |
| `.dash-tab.active` | 激活状态的标签（深色渐变背景） |
| `.dash-page` | 内容页面容器，默认 `display: none` |
| `.dash-page.active` | 激活状态的页面，`display: block` + 淡入动画 |
| `.dash-main` | 主内容区域容器 |

### JavaScript 功能

1. **标签切换**：点击标签 → 更新 active 状态 → 显示对应页面
2. **键盘导航**：左右方向键在标签间切换
3. **URL同步**：切换标签时更新 URL 锚点（`history.replaceState`）
4. **状态恢复**：页面加载时从 URL 恢复上次查看的标签
5. **平滑滚动**：切换后自动滚动到导航条位置

## 📝 注意事项

### 1. **Agent 手写报告适配**

如果报告由 Report Generation Agent 手写，需要在 Agent 的 system prompt 中增加看板结构说明：

```markdown
# 看板式报告结构（可选）

如果运营要求看板式报告，使用以下结构：
1. Hero 始终在最前面
2. 导航条使用 <nav class="dash-nav">
3. 每个 section 包裹在 <div class="dash-page" id="pg-xxx">
```

### 2. **打印友好性**

CSS `@media print` 规则确保打印时：
- 隐藏导航条
- 所有 `dash-page` 自动展开（`display: block !important`）
- 避免跨页断裂（`page-break-before: auto`）

### 3. **浏览器兼容性**

- 现代浏览器（Chrome 90+、Firefox 88+、Safari 14+）完全支持
- IE11 不支持（但 IE11 已停止维护）
- `backdrop-filter` 在 Firefox 中需要手动开启（可降级到纯色背景）
