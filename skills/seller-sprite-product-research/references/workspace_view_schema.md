# 工作台视图结构

## 目标

定义后续网页工作台和报告页面需要展示的卡片结构。

## 卡片

| 卡片 | 内容 |
|---|---|
| 候选品任务卡 | 站点、关键词、产品形态、禁区、属性勾选 |
| 市场扫描卡 | 市场规模、价格带、集中度、新品占比、趋势 |
| 竞品池卡 | Top10 标杆组、近半年放量新品组、结构补充组 |
| 利润参考卡 | 售价、采购价、头程、FBA、仓储、入库配置费、广告费率、毛利 |
| 退货风险卡 | 退货率、来源、风险提示 |
| 知产/合规卡 | 风险类型、可能材料、待复核项 |
| 状态卡 | 继续看/试做/观察/先放弃、理由、下一步 |
| 报告摘要卡 | 关键结论、行动建议 |
| 看板卡 | 机会排序、风险提示、简化图表 |

## 规则

- 一张卡只放一个判断主题。
- 结果必须可追溯到数据底表或原始来源。
- 高风险项必须显式提示，不要隐藏。
