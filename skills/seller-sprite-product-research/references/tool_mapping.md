| 目标 | 工具 |

| 发现候选市场/类目/关键词 | `market_research`、`product_node`、`keyword_research` |
| 市场统计 | `market_research_statistics` |

| 目标 | 工具 |
|---|---|

## 规则

1. 工具名称以卖家精灵 MCP 实际可用列表为准。
2. 不确定字段先记录，不直接写强结论。
3. 任何结论必须能追溯回 MCP 原始索引或手填来源。
