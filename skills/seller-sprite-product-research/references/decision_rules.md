# 决策规则

## 状态

| 状态 | 含义 |
|---|---|
| 继续看 | 市场、竞品、利润、风险暂时说得通 |
| 试做 | 有机会，但关键假设未验证 |
| 观察 | 有趋势或痛点，但证据不足 |
| 先放弃 | 利润差、风险高、无法差异化或数据反证强 |

## 基础规则

1. Top100 不完整，不生成正式状态卡。
2. 没有来源和采集时间，不写强判断。
3. 利润结果只算参考值。
4. 仓储费早期按建议售价 3% 简化估算。
5. FBA 费用、入库配置费、售价、采购价、退货率、广告费率由运营手填。
6. 头程费用按计费重和渠道单价估算，计费重取体积重和实际重较大值。
7. 评论插件只在深挖阶段启用。
8. 知产、合规和最终状态都要人工复核。

## 风险提示

| 风险 | 处理 |
|---|---|
| 结构性硬伤 | 只做风险提示，不直接下结论 |
| 退货率明显高于平均 | 标高风险 |
| 知产/合规信息不足 | 标待确认 |
| 数据来源不清 | 不进强结论 |
