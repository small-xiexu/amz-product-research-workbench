# 卖家精灵导出指令完整性规范

卖家精灵导出清单必须按真实功能入口写清楚。不要只写“卖家精灵入口”或泛泛写“市场分析/关键词数据”；要告诉运营从哪个菜单进去、输入什么、导出什么、文件放哪里。

## 语言口径

- 卖家精灵的实际输入对象必须使用目标站点语言：US/CA/UK 默认用英文关键词或英文类目名，DE/JP 等站点使用当地站点可识别语言。
- 中文可以用于「路线/类目归属」说明，例如“路线 A / 主推路线”，但不能作为美国站卖家精灵 `查竞品`、`选产品`、`选市场`、`关键词选品`、`ABA数据选品` 的实际输入词。
- 卖家精灵导出清单必须只使用目标站点可识别的输入对象；中文内部路线名只能作为说明，不能混进实际复制到卖家精灵的输入框。
- 排除关键词也应使用目标站点语言；美国站用英文排除词，如 `electric`、`vacuum`、`spray`、`liquid`、`floor`、`window film`。

截图中可用入口按三组理解：

| 菜单组 | 入口 | 本项目用途 |
|---|---|---|
| 大数据选品 | 查竞品 | 用关键词或类目找相似竞品、Top 商品、价格带和评论门槛 |
| 大数据选品 | 选产品 | 找候选产品、低评论有销量样本、新品或相似形态 |
| 大数据选品 | 选市场 | 查大类/小类市场容量、竞争结构、价格带、新品机会、类目淡旺季 |
| 大数据选品 | 关键词选品 | 补充关键词池，不能替代 ASIN 反查和 ABA |
| 大数据选品 | ABA数据选品 | 查真实搜索、点击和转化集中度 |
| 大数据选品 | 产品库 | 补充 ASIN 池、类目路径或候选商品明细 |
| 运营推广 | 查流量来源 | 看竞品流量来源和关联流量 |
| 运营推广 | 关键词监控 | 持续跟踪词，不作为一次性导出主入口 |
| 运营推广 | 店铺上新监控 / 产品监控 | 补充新品或竞品动态，非首轮必导 |
| 浏览器插件 | 市场分析 | 在 Amazon 页面或类目页查看/导出市场分析 |
| 浏览器插件 | 关键词反查 | 在商品页或 ASIN 上反查关键词 |
| 浏览器插件 | 评论下载 | 卖家精灵插件评论下载；本项目评价主流程仍优先用自有评论慢速采集助手 |

## 固定输出格式

```text
本轮卖家精灵数据放置目录：
<绝对路径>

导出 <序号>：<报表名称>
- data_role：<数据角色>
- 菜单组：<大数据选品 / 运营推广 / 浏览器插件>
- 卖家精灵入口：<查竞品 / 选产品 / 选市场 / 关键词选品 / ABA数据选品 / 产品库 / 查流量来源 / 市场分析 / 关键词反查 / 评论下载>
- 站点：<US / CA / UK / DE / JP ...>
- 月份/时间：<最近30天 / 最近完整月 yyyy-MM / 最近3-6个月 / 指定时间范围>
- 输入对象：<实际复制到卖家精灵的站点语言关键词、类目名或 ASIN；US/CA/UK 默认英文>
- 路线/类目归属：<路线名 / 类目名 / 大类 / 小类 / 混池 / 对照 / 排除>
- 导出范围：<Top100 / Top200 / 全部可导字段 / 最近完整月 / 截图兜底>
- 必要字段：<必须包含的列>
- 文件命名建议：<站点_data_role_对象_日期.xlsx>
- 失败兜底：<搜不到时替代对象、跳过条件、截图要求>
- 用途：<后续判断什么>
```

## data_role 到入口映射

| data_role | 首选入口 | 备选入口 | 输入对象 | 用途 |
|---|---|---|---|---|
| `broad_market` | 大数据选品 / 选市场 | 浏览器插件 / 市场分析 | 候选大类、上层类目短词 | 看大类容量和类目淡旺季 |
| `subcategory_market` | 大数据选品 / 选市场 | 浏览器插件 / 市场分析 | 候选小类、ASIN 反推小类 | 看小类价格带、集中度、新品机会 |
| `reference_asin_search` | 大数据选品 / 查竞品 | 大数据选品 / 选产品、产品库 | 相似卖点关键词、候选小类、参考 ASIN 相关搜索 | 建立参考 ASIN 池 |
| `product_candidate_pool` | 大数据选品 / 选产品 | 大数据选品 / 产品库 | 目标站点语言的产品形态词、路线词、候选小类；中文路线名仅作说明 | 补充候选商品、新品和低评论样本 |
| `reverse_asin_keywords` | 浏览器插件 / 关键词反查 | 运营推广 / 查流量来源 | 参考 ASIN Top5/Top10 | 反查关键词并生成运营式词表 |
| `aba_keywords` | 大数据选品 / ABA数据选品 | 无；缺失则标 ABA 缺口 | 主查词、补查词、路线词、精准长尾词 | 看点击/转化集中度 |
| `keyword_pool_expand` | 大数据选品 / 关键词选品 | 关键词优化 / 关键词挖掘、拓展流量词 | 主查词、补查词、路线词 | 补充词池；不能直接定义市场 |
| `new_release_signal` | 大数据选品 / 选市场 | 大数据选品 / 选产品、产品库、店铺上新监控 | 候选小类、目标价格段 | 判断新品榜、新品冷启动和低评论机会 |
| `mixed_pool_benchmark` | 大数据选品 / 查竞品 | 大数据选品 / 选市场、浏览器插件 / 市场分析 | 明显混池类目、混池词、对照 ASIN | 做排除和对照 |
| `traffic_source_check` | 运营推广 / 查流量来源 | 浏览器插件 / 关键词反查 | 参考 ASIN、头部竞品 ASIN | 看竞品流量来源和关联流量 |

## 三类必须分清

### 1. 选市场

用途：查市场和类目，不是查精准长尾词。

适合输入：

- 候选大类
- 候选小类
- 参考 ASIN 反推出来的类目名
- 上层类目短词

不适合输入：

- 过长的精准长尾词
- 单个功能卖点词
- 明显混入其他使用场景的词

输出重点：

- 市场容量
- Top100 月销量和销售额
- 均价/中位价
- 价格分布
- 商品/品牌/卖家集中度
- 评论门槛
- 新品或上架时间分布
- 类目趋势或淡旺季

### 2. 查竞品 / 选产品

用途：找相似竞品和候选 ASIN，不能替代市场分析。

适合输入：

- 目标站点语言的产品形态词
- 目标站点语言的路线词
- 目标站点语言的候选小类或类目名
- 目标站点语言的相似卖点关键词
- 竞品 ASIN

输出重点：

- ASIN
- 标题
- 品牌
- 类目路径
- 价格
- 月销量
- 评论数和评分
- 上架时间
- BSR 或排名
- 是否新品或低评论仍有销量

### 3. 关键词反查 / ABA数据选品

用途：验证搜索需求和转化集中度，不能替代大类/小类市场判断。

关键词反查输入：

- 参考 ASIN Top5/Top10
- 主推代表 ASIN
- 高销量标杆 ASIN
- 新品样本 ASIN
- 高客单对照 ASIN
- 痛点参考 ASIN

ABA 数据选品输入：

- 主查词
- 补查词
- 路线词
- 精准长尾词

输出重点：

- 关键词
- 搜索量或搜索频率排名
- 点击最高 ASIN
- 点击份额
- 转化份额
- 自然排名/广告排名，如反查表支持
- CPC/PPC，如工具支持
- 月份

## 参考 ASIN 反查规则

关键词反查不能只写“反查竞品”。必须列清楚：

| 字段 | 要求 |
|---|---|
| ASIN | 直接列可复制的 ASIN |
| 代表路线 | 说明属于哪条产品路线 |
| ASIN 角色 | `primary_reference` / `high_sales_benchmark` / `new_release_sample` / `premium_benchmark` / `painpoint_reference` / `excluded_reference` |
| 相似理由 | 形态、卖点、场景、规格、价格带为什么相近 |
| 优先级 | 必导 / 备选 / 暂不导 |
| 首选入口 | 浏览器插件 / 关键词反查 |
| 兜底入口 | 运营推广 / 查流量来源 |
| 导出范围 | 关键词列表、搜索量、CPC、自然排名、广告排名、流量占比、关联 ASIN |

## 价格带和新品机会导出规则

市场分析、查竞品或选产品明细必须能支持价格段判断，不允许只导概览均价。

必要字段：

- ASIN
- 标题
- 品牌
- 类目路径或类目节点
- 价格
- 月销量
- 月销售额
- 评论数
- 评分
- 上架时间或上架时长
- BSR / 排名
- 卖家类型或发货方式，如可导
- 新品标记、新品榜信息或近 6 个月上架样本，如可导

后续分析必须能计算或目视判断：

- 每个价格段商品数、销量占比、销售额占比。
- 每个价格段 Top3 商品占比、Top3 品牌占比。
- 目标价格段的评论门槛。
- 低评论仍有销量的新品样本。
- 哪个小类目更适合上新品榜或做冷启动。

## 失败兜底

| 场景 | 处理 |
|---|---|
| 候选小类在选市场搜不到 | 换上层类目短词、参考 ASIN 所在类目、相邻类目；仍无结果则截图并标 `data_gaps` |
| 长尾词无法选市场 | 不用长尾词硬搜市场，改用参考 ASIN 类目或短类目词 |
| 查竞品结果混池太多 | 换更贴近产品形态的路线词，或加候选小类约束；保留混池截图作排除证据 |
| 选产品结果过宽 | 换产品形态词、规格词或小类；仍过宽则只作候选池补充，不进市场结论 |
| 美国站输入中文搜不到或结果异常 | 改用英文产品形态词、英文类目名或参考 ASIN；中文词只保留为内部路线说明 |
| ASIN 关键词反查失败 | 用浏览器插件逐个 ASIN 反查；仍失败则走运营推广 / 查流量来源截图兜底 |
| ABA 搜不到长尾词 | 换主查词或上位词；仍无结果标 ABA 缺失 |
| 新品榜入口不可用 | 用选市场/选产品里的上架时间、近 6 个月新品和低评论样本替代 |
| 插件入口无法导出 | 保存截图和页面 URL，标注截图口径，不能伪装成 Excel 明细 |
| 导出字段缺失 | 记录缺失字段和影响，不强行出正式深挖结论 |

## 对话输出自检

发给运营前检查：

- 是否每份数据都有 `data_role`。
- 是否写清菜单组和真实入口，而不是只写“卖家精灵入口”。
- 是否覆盖选市场、查竞品/选产品、关键词反查、ABA 数据选品、新品/低评论样本和混池对照。
- 是否每个入口都有可复制输入对象。
- 是否实际复制到卖家精灵的输入对象使用目标站点语言，且没有把中文内部路线名混进卖家精灵清单。
- 是否说明精准长尾词不能直接当选市场类目词。
- 是否给了文件放置目录和命名规则。
- 是否写清失败兜底和截图条件。
- 是否说明每份数据的用途。
- 是否把必导、备选、暂不导分开。
- 是否没有写入当前品类、ASIN、关键词、供应商或价格的硬编码样例。
