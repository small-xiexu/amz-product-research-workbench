# 1688 供应链采集指令完整性规范

## 目的

当流程进入供应链验证时，Codex 不能只说“去 1688 搜这些词”。必须把插件或采集工作台每个字段怎么填、为什么这样填、导出后放哪里讲清楚，让运营能照单执行。

本文件是通用规范，不允许写入具体品类的固定词。具体品类的搜索词、排除词、价格范围和兜底策略，必须生成到本轮 `runs/<run_id>/supply_chain_collection_instructions.md`。

## 必须输出的字段

每次让运营采集 1688 数据时，必须逐项给出：

| 字段 | 必须说明 |
|---|---|
| 采集入口 | 使用哪个页面或插件，如 `1688 · 供应链采集 / 采集工作台` |
| 搜索关键词 | 一行一个中文供应链词，必须可直接复制 |
| 类目相关词 | 用于保留相关商品的词，避免插件误收其他类目 |
| 排除词 | 必须排除的产品形态、禁区和混池词 |
| 目标采购价下限 | RMB 数字；无下限时写 `0` 或留空，并说明 |
| 目标采购价上限 | RMB 数字；要结合 Amazon 目标售价、早期粗采购价和路线高低配 |
| 最大起订量 | 数字；新手验证阶段建议控制 MOQ |
| 关注标签 | 如现货、定制、一件代发、跨境、48小时发货 |
| 每词自动页数 | 建议页数和原因 |
| 开始采集动作 | 明确点击 `开始自动采集`，等待状态完成 |
| 导出动作 | 明确导出候选，或保存截图 + 商品链接列表 |
| 存放目录 | 本轮 run 的 `inputs/supply_chain/` 绝对路径 |
| 命名建议 | 文件名应包含日期、路线、关键词或批次 |
| 失败兜底 | 搜不到、误收太多、采集停止时怎么调整 |

## 生成步骤

### 1. 从路线矩阵生成搜索关键词

搜索关键词必须来自本轮路线矩阵，而不是固定模板。每条保留路线至少给 2-3 个中文词：

- 产品通用名：供应商最可能使用的中文品类名。
- 核心结构词：材质、部件、组合方式、规格形态。
- 套装/场景词：组合款、专业款、便携款、替换件或目标场景。

若 Amazon 英文词和中文供应链词可能不一致，必须列出同义词，并说明哪个优先跑。

### 2. 从产品边界生成类目相关词

类目相关词用于保留相关商品，不能过窄。应覆盖：

- 品类核心名词
- 关键部件名
- 主要材质或功能词
- 套装、配件、替换件等形态词

不要把禁区词写进类目相关词。

### 3. 从用户禁区和混池风险生成排除词

排除词必须来自本轮上下文，包括：

- 用户明确不做的禁区
- 卖家精灵/Sorftime/VOC 发现的混池形态
- 合规或物流上不适合本轮的形态
- 明显不同使用场景的旁支品类

### 4. 生成采购价上下限

采购价上下限必须解释来源：

- 若已有 Sorftime/1688 粗采购价，用其有效 RMB 样本区间作为参考。
- 若目标售价已明确，用目标售价、预期毛利、体积/重量风险倒推一个保守上限。
- 若路线包含高低配，允许先放宽上限保留高配样本，但必须说明原因。
- 若结果过多低价无效样本，给出提高下限的兜底。

### 5. 生成 MOQ 和页数

- 最大起订量默认不超过 `500`，除非品类普遍 MOQ 更高。
- 新手试单优先保留现货、小 MOQ、一件代发、跨境货源。
- 每词自动页数默认 `2`；有效候选少于 15 个时，再提高到 `3-5`。

### 6. 生成关注标签

关注标签必须围绕本轮验证目标生成。常用候选包括：

```text
现货，定制，一件代发，跨境，48小时发货，可改材质，可换包装，可贴牌，支持小单
```

如果 VOC 已暴露结构痛点，关注标签和供应商问询项要围绕这些结构痛点，而不是只写泛标签。

## 通用输出模板

Codex 给运营的 1688 采集操作单必须包含以下结构：

```markdown

入口：[页面或插件名]
站点口径：只看 1688 中国站，采购价只接受 RMB/CNY。

## 2. 按字段填写

## 3. 开始采集

点击 `开始自动采集`，等待采集完成。

## 4. 导出或保存
```

## 数据口径

- 只看 `1688.com` 中国站。
- 采购价必须是 RMB/CNY。
- Alibaba 国际站 USD、非 1688 域名、币种不明样本不得进入采购价区间。
- 供应链采集只提供采购价和供应形态证据，不替代利润模板、FBA 费用、头程费用和合规复核。

## 文件存放

导出或手工整理文件必须放入：

```text
runs/<run_id>/inputs/supply_chain/
```

推荐命名：

```text
1688-supply-<direction>-YYYYMMDD.xlsx
1688-supply-<direction>-links-YYYYMMDD.md
```

如果插件不能导出 Excel：

1. 保存商品链接列表，至少 15-25 个候选。
2. 每个候选保留标题、价格、供应商名、商品链接。
3. 对重点商品截图详情页，优先截图规格、包装、重量、材质、起订量和主图。
