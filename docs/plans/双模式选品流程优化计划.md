# 双模式选品流程优化计划

> 创建日期：2026-06-12
> 依据：架构对话，确认模式一/模式二的双数据源并行采集设计

## 背景

确认两种选品模式，并扩展 Sorftime 的使用时机：
- **模式一（模糊探索）**：Sorftime 初探与卖家精灵导出并行，在运营操作期间 Claude 同步摸清方向信号
- **模式二（指定方向）**：Sorftime 前置快验，通过后再要求运营导出卖家精灵，避免无效导出

两个模式都使用双数据源，区别只在**顺序和主导权**：
- 模式一：卖家精灵先行（宽扫），Sorftime 并行
- 模式二：Sorftime 先行（快验），卖家精灵后置（定向）

两个模式收敛到同一深挖流程（`candidate-deep-dive` Skill），产出同样的完整报告。
