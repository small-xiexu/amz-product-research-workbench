# 系统扩展实施计划

> 创建日期：2026-06-12
> 依据：架构对话，确认三项扩展方向

## 背景

三项扩展合并推进，最终目标：
1. 评论插件直接接入工作台，运营点一下按钮即可完成评论数据交付
2. Sorftime 数据能进入结构化报告，不再只是对话层的文字判断
3. 新数据源接入只需写一个 Adapter，核心脚本零改动
