# 亚马逊选品全流程产品路线图

更新日期：2026-06-07

## 最终目标

做一套能从模糊选品意图一路走到候选品池、深挖报告和看板的全流程系统：

`输入选品意图 -> 候选市场/关键词发现 -> 候选品池 -> 初筛评分 -> 重点候选深挖 -> 利润参考 -> 退货风险 -> 知产/合规 -> 评论/VOC -> 差异化机会 -> 报告/摘要/看板 -> 复盘`

第一阶段不直接做完整应用。先跑通选品逻辑、数据口径和报告生成，再逐步做成工作台。

## 为什么不一开始做应用

| 原因 | 说明 |
|---|---|
| 业务规则还在收敛 | 利润、退货、竞品、合规等口径需要先验证 |
| 手动导出字段还要确认 | 先确认卖家精灵各页面能导出哪些 Excel/CSV 字段；后续只用 MCP 增强 |
| 报告样式还没定 | 主报告、摘要、看板需要先做静态 mock |
| 交互点不能提前固化 | 成本补数、竞品复核、状态修改要等流程稳定后再做页面 |

先做本地报告生成器，能避免一开始陷进前端、账号、数据库和复杂交互。

## 产品形态演进

| 阶段 | 产品形态 | 核心目标 |
|---|---|---|
| V0 | 方案和静态 mock | 定范围、定字段、定报告样式 |
| V1 | 候选品发现 Skill + 本地报告生成器 | 输入选品意图后生成候选品池，再对重点候选生成 Excel、Markdown、摘要、HTML 看板 |
| V2 | 轻量网页工作台 | 支持补数、复核竞品、调整利润参数、重新生成报告 |
| V3 | 深挖模块 | 接入评论插件，做 VOC、改品机会、图片/A+和推广方向 |
| V4 | 完整选品应用 | 历史调研库、多品类横向比较、复盘、协作 |
| V5 | 增强数据源 | Playwright、Google Trends、1688、飞书/任务同步 |

## V0：方案和静态 mock

目标：开发前把方向定住。

产物：

- V1 范围冻结
- 字段来源表
- 报告三件套静态 mock
- 卖家精灵手动导出数据清单
- `research_package` 数据结构草案

不做：

- 不写正式功能代码
- 不接完整自动化真实数据流程
- 不做网页应用

通过标准：

- 清楚哪些字段来自卖家精灵手动导出、哪些手填、哪些系统计算，后续 MCP 如何替换手动采集层
- 清楚 V1 报告长什么样
- 清楚哪些模块必须进 V1，哪些放 V2+

## V1：Skill + 本地报告生成器

目标：从模糊选品意图发现候选品池，再对重点候选跑通初筛闭环。

输入：

- 站点
- 大概方向，可为空
- 明确禁区
- 偏好条件
- 供应链优势，可选
- 运营假设，可选

不在初始输入阶段要求：

- 采购价
- FBA 费用
- 头程费用
- 入库配置费
- 具体 ASIN
- 最终售价

核心模块：

- 候选市场和关键词发现
- 候选品池
- 市场扫描
- 竞品池：Top10 标杆组、近半年放量新品组、结构补充组
- 关键词和趋势
- 利润参考
- 退货风险
- 知产/合规初筛
- 状态卡

输出：

- `research_package.json`
- `data.xlsx`
- `report.md`
- `summary.md`
- `dashboard.html`

不做：

- 不做网页应用
- 不强制接评论插件
- 不做完整图片/A+
- 不做完整推广节奏
- 不做历史库和协作

## V2：轻量网页工作台

目标：把高频人工复核点做成页面。

页面：

- 调研任务输入
- 产品属性勾选
- 市场扫描
- 竞品池复核
- 利润参数调整
- 风险卡片
- 报告/摘要/看板预览

核心能力：

- 补成本
- 删除/替换竞品 ASIN
- 修改状态
- 重新生成报告
- 下载 Excel/Markdown/HTML

V2 仍然保持轻量，不做账号权限和复杂协作。

## V3：评论和机会深挖

目标：从“能不能继续看”进入“怎么做更有机会”。

接入自有评论插件：

`筛出 3-5 个核心 ASIN -> 评论插件导出 Excel + HTML AI 报告 -> 系统读取 Excel -> 生成 VOC 证据账本`

新增模块：

- 评论样本质量
- 痛点/亮点归类
- 结构性问题验证
- 改品机会
- 图片/A+方向
- 竞对推广节奏
- 压力测试

原则：

- 评论插件不进 V1 初筛主流程
- Excel 是机器分析主输入
- HTML AI 报告是人工阅读材料
- 痛点结论必须能追溯到具体评论

## V4：完整选品应用

目标：从单次报告生成，升级成持续选品工作台。

能力：

- 历史调研库
- 多品类横向比较
- 机会库
- 复盘记录
- 状态流转
- 团队协作
- 权限和账号
- 可筛选数据表
- 可编辑参数和重算

这个阶段才考虑完整应用形态。

## V5：增强数据源

目标：补足卖家精灵手动导出/MCP 之外的数据。

可能增强：

- Playwright 抓商品页公开信息
- Google Trends 补趋势
- 1688/供应链价格验证
- 飞书或任务系统同步
- 社媒趋势和情绪信号

这些都不进 V1，避免首版过重。

## 数据来源分工

| 数据类型 | 来源 | 阶段 |
|---|---|---|
| 市场规模、价格带、Top100 | 卖家精灵手动导出，MCP 后续增强 | V1 |
| 关键词、趋势、CPC 参考 | 卖家精灵手动导出，必要时补 Google Trends | V1/V5 |
| 竞品详情、Keepa、Coupon | 卖家精灵手动导出，MCP 后续增强 | V1/V2 |
| 类目退货率 | 卖家精灵手动导出，后台大类退货率作参考 | V1 |
| 成本参数 | 手填 | V1 |
| 利润、头程、毛利率 | 系统计算 | V1 |
| 知产/合规 | 卖家精灵手动导出/MCP + 入口库 + 人工复核 | V1 |
| 评论 VOC | 自有评论插件 | V3 |
| 历史复盘 | 应用数据库 | V4 |

## 当前最近三步

1. 做 V1 范围冻结文档。
2. 做字段来源表。
3. 做一份静态报告 mock。

这三步完成后，再开始写 `SKILL.md` 和本地报告生成器。
