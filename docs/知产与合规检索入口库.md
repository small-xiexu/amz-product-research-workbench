# 知产与合规检索入口库 v0.1

更新日期：2026-06-07

## 用途

这份文档用于选品早期初筛：

- 是否存在外观/实用/发明专利风险
- 是否存在商标/版权风险
- 是否可能需要合规认证或测试报告
- 是否需要在继续选品前先人工或专业复核结论只能作为初筛，不替代律师、专利代理机构、检测机构或 Amazon 合规团队的最终判断。这里的“高/中/低/强风险”也是选品阶段的筛查等级，不是最终合规结论。

## 对选品技能的价值

运营整理的网址有直接价值，可以作为技能的人工检索入口库：

| 价值 | 怎么用 |
|---|---|
| 统一入口 | 避免每次临时找专利、商标、版权网址 |
| 前置排雷 | 在 Top100 深挖前先判断是否有明显侵权或认证雷区 |
| 证据归档 | 每次检索记录关键词、入口、链接、截图和风险等级 |
| 人工复核 | AI 只做初筛，疑似高风险交给运营、代理机构或检测机构确认 |
| 决策联动 | 强风险直接影响立项/试做/观察/淘汰，不再只看销量和利润 |

## 推荐检索顺序

### 1. 先判断风险类型

| 风险类型 | 典型触发 |
|---|---|
| 外观专利 | 产品形状、结构、图案、包装外观高度相似 |
| 实用/发明专利 | 核心功能、连接方式、使用方法、内部结构可能被保护 |
| 商标 | 标题、五点、A+、图片里出现品牌词、功能词、型号词、图案词 |
| 版权 | 图片、图案、IP 形象、说明书、A+文案可能复制他人作品 |
| 合规认证 | 儿童、电子、无线、电池、食品接触、化妆品、医疗/健康、激光/UV 等 |

### 2. 按目标站点检索

| 目标市场 | 优先入口 |
|---|---|
| 美国 | USPTO、USPTO Trademark Search、CPSC、FCC、FDA |
| 欧盟 | EUIPO、DesignView、TMview、Espacenet、CE/REACH/RoHS 相关入口 |
| 日本 | J-PlatPat |
| 中国供应链参考 | CNIPA、中国商标网 |
| 全球初筛 | WIPO PATENTSCOPE、WIPO Global Brand Database、WIPO Global Design Database |

### 3. 输出风险等级

| 等级 | 处理 |
|---|---|
| 低 | 继续分析，保留检索记录 |
| 中 | 继续试做/观察，标注待复核 |
| 高 | 暂停立项，先做人工/专业复核 |
| 强风险 | 淘汰或更换设计/功能/关键词 |

## 合规认证早期判断

选品早期必须根据“产品属性 + 目标站点 + 使用人群 + 使用场景”判断可能需要哪些合规材料。

| 产品属性 | 美国常见触发 | 欧盟/英国常见触发 | 早期判断 |
|---|---|---|---|
| 儿童用品/玩具 | CPSC、CPC、CPSIA、ASTM F963 等 | CE 玩具安全、EN71、UKCA | 强制前置判断 |
| 普通受 CPSC 规则约束消费品 | GCC | 通用产品安全规则 | 需查适用标准 |
| 带电/电子产品 | FCC、UL/ETL/NRTL、能效等 | CE、EMC、LVD、RoHS、UKCA | 前置判断 |
| 蓝牙/Wi-Fi/遥控/RF | FCC Certification / SDoC、FCC ID | RED、CE、UKCA | 前置判断 |
| 锂电池/含电池 | UN38.3、MSDS/SDS、UL 相关测试、运输要求 | UN38.3、RoHS、Battery Regulation | 前置判断 |
| 充电器/电源适配器 | UL/ETL/NRTL、FCC、能效 | CE、LVD、EMC、RoHS | 前置判断 |
| 食品接触材料/厨房用品 | FDA food contact、Prop 65 | LFGB、EU food contact、REACH | 前置判断 |
| 化妆品/护肤/接触皮肤液体 | FDA 标签、MoCRA、成分和安全证明 | EU Cosmetics Regulation、UK cosmetic rules | 高风险品类 |
| 医疗/健康宣称 | FDA medical device / OTC 风险 | MDR/UK medical device 风险 | 谨慎或避开 |
| 激光/UV/LED/辐射产品 | FDA CDRH radiation-emitting products | CE、相关安全标准 | 前置判断 |
| PPE/防护用品 | NIOSH/FDA/OSHA 等视产品而定 | PPE Regulation、CE/UKCA | 高风险品类 |

早期预判输出不写“确定需要某证书”，而写：

- 可能触发的监管领域
- 可能需要的证书/测试/报告
- 触发原因
- 缺少哪些产品属性
- 是否需要检测机构、律师或 Amazon 合规团队复核
- 对决策的影响：继续 / 试做 / 观察 / 淘汰

## 合规判断所需输入

运营或产品开发需要尽早提供：

- 目标站点
- 产品用途
- 使用人群：儿童/成人/宠物
- 是否带电
- 是否带无线/RF
- 是否含电池
- 是否接触食品
- 是否接触皮肤/入口/眼睛
- 是否有医疗、治疗、健康、安全、防护宣称
- 是否含激光、UV、LED、加热、压力、运动部件
- 材质和涂层
- 包装和说明书计划没有这些输入时，不能给“合规低风险”结论。

## 接入到选品流程

| 流程节点 | 使用方式 |
|---|---|
| 第0步 调研边界 | 运营填写目标站点、产品属性、已知风险、禁区 |
| 第1.5步 知产/合规初筛 | 按风险类型和目标站点检索，产出初筛表 |
| 第7步 评论痛点 | 如果评论高频提到安全、过热、破损、儿童风险，需要回写合规风险 |
| 第11步 利润测算 | 把测试、认证、整改、包装标签成本作为敏感性参数 |
| 第14步 决策 | 高风险未排除前不能给 立项 |

## 输出模板

| 字段 | 说明 |
|---|---|
| 产品/机会 | 候选产品或功能 |
| 目标站点 | US/EU/UK/CA/JP 等 |
| 风险类型 | 外观/实用发明/商标/版权/认证 |
| 触发原因 | 为什么需要查 |
| 检索入口 | 使用哪个数据库 |
| 检索关键词 | 英文关键词、类目词、功能词、申请人/品牌 |
| 初筛结果 | 低/中/高/强风险 |
| 证据链接 | 检索结果 URL 或截图位置 |
| 下一步 | 继续/人工复核/专业复核/淘汰 |
