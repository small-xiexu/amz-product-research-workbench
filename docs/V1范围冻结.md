# V1 范围冻结

更新日期：2026-06-07

## V1 目标

从模糊选品意图生成候选品池，再对重点候选跑通初筛闭环，生成可复核的报告三件套和数据底表。

## V1 实施顺序

1. 先定义 `selection_brief.json`，承接站点、禁区、偏好、大概方向和供应链优势。
2. 用样例/导入数据跑通候选品池结构。
3. 再接卖家精灵 MCP，把市场、关键词、Top100、竞品、风险字段灌进候选品池。
4. 对重点候选生成 `research_package.json`。
5. 最后补 Excel 明细、来源索引和报告自检。

## V1 输入

- 站点
- 大概方向，可为空
- 明确禁区
- 偏好条件
- 供应链优势，可选
- 运营假设，可选

## V1 产物

- `research_package.json`
- `data.xlsx`
- `report.md`
- `summary.md`
- `dashboard.html`

## V1 必做

- 候选市场和关键词发现
- 候选品池
- 市场扫描
- Top100 完整明细
- Top100 基础属性打标
- 属性交叉分析
- 竞品池：Top10 标杆组、近半年放量新品组、结构补充组
- 关键词和趋势
- 利润参考
- 退货风险
- 知产初筛
- 合规初筛
- 状态卡

## V1 不做

- 不做完整网页应用
- 不做评论深挖
- 不做图片/A+方向
- 不做推广节奏深挖
- 不做历史库
- 不做多人协作

## V1 规则

1. Top100 不完整，不进入正式结论。
2. 没有来源和时间，不写强判断。
3. 正式深挖报告必须完成 Top100 基础属性打标和交叉分析。
4. 多 SKU/变体链接必须标记统计口径，避免把子体表现误算成父体表现。
5. 利润结果只做参考值。
6. 仓储费早期统一按建议售价 3% 简化估算。
7. FBA 费用、入库配置费、售价、采购价、实际重量、体积重、退货率、广告费率只在候选品进入利润复核后由运营手填。
8. 入库配置费不确定时标记待补，不默认 0。
9. 头程费用按计费重和渠道单价估算，计费重取体积重和实际重较大值。
10. 退货率、知产、合规、最终状态都保留人工复核。

## V1 通过标准

- 能生成 `research_package.json`
- 能生成 Excel 数据底表
- 能完成 Top100 明细、基础属性打标和交叉分析
- 能标记多 SKU/变体统计口径
- 能生成主报告、摘要、看板
- 能追溯每个强判断的来源
- 能输出继续看/试做/观察/先放弃
