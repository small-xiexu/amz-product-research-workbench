# V1 范围冻结

更新日期：2026-06-07

## V1 目标

跑通一个候选品类的初筛闭环，生成可复核的报告三件套和数据底表。

## V1 输入

- 站点
- 候选品类或关键词
- 产品形态
- 明确禁区
- 运营手填成本参数

## V1 产物

- `research_package.json`
- `data.xlsx`
- `report.md`
- `summary.md`
- `dashboard.html`

## V1 必做

- 市场扫描
- 竞品池：Top10 标杆组、近半年放量新品组、结构补充组
- 关键词和趋势
- 利润参考
- 退货风险
- 知产初筛
- 合规初筛
- 状态卡

## V1 不做

- 不做完整网页应用
- 不做评论深挖
- 不做图片/A+方向
- 不做推广节奏深挖
- 不做历史库
- 不做多人协作

## V1 规则

1. Top100 不完整，不进入正式结论。
2. 没有来源和时间，不写强判断。
3. 利润结果只做参考值。
4. 仓储费按建议售价 3% 简化估算。
5. FBA 费用、入库配置费、售价、采购价、退货率、广告费率由运营手填。
6. 头程费用按计费重和渠道单价估算，计费重取体积重和实际重较大值。
7. 退货率、知产、合规、最终状态都保留人工复核。

## V1 通过标准

- 能生成 `research_package.json`
- 能生成 Excel 数据底表
- 能生成主报告、摘要、看板
- 能追溯每个强判断的来源
- 能输出继续看/试做/观察/先放弃
