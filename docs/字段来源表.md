# 字段来源表

更新日期：2026-06-08

## 说明

这份表只负责回答一件事：每个字段从哪来。

表里的“卖家精灵导出/MCP”表示目标接入来源。V1 优先读取用户从卖家精灵手动导出的 Excel/CSV 或整理表；后续自动化只保留 MCP 路线，不再规划 HTTP API 接入。当前代码阶段先用样例数据包跑通输出；真实导入前需要确认导出文件字段、筛选条件、站点和导出时间。

|---|---|---|
| 站点 | 运营输入 | 必填 |

## 规则

1. 没有来源的不进强结论。
2. 手填字段必须在报告里标记。
3. 系统计算字段必须能回溯公式。
4. 评论结论必须能追溯到具体评论。
