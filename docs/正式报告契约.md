# 正式报告契约

本项目不新增独立 `payload_v2`。正式报告的唯一事实源仍是 `research_package.json`，报告渲染器只把它投影为 `report.md`、`report.html`、`dashboard.html`、`summary.md` 和 `data.xlsx`。

详细字段说明见 `docs/research_package字段契约.md`。本文只约束正式报告和 Excel 回表关系。

## 单一事实源

| 对象 | 作用 | 约束 |
|---|---|---|
| `research_package.json` | 正式报告唯一结构化输入 | 不从 Markdown/HTML 反解析事实 |
| `report.md` | 12 章正式报告 | 展示数据、口径、结论和下一步 |
| `report.html` | 运营阅读版 | 不能补造 `research_package` 中不存在的数据 |
| `data.xlsx` | 回表底表 | 每个强判断必须能回到对应 Sheet |
| `workflow_summary.json` | 流程运行摘要 | 标记评论、利润、知产/合规、交互状态是否已接入 |

## 12 章槽位

| 章节 | 数据来源 | 必须回表 |
|---|---|---|
| Executive Summary / 当前结论 | `status_card`、`decision_review`、`report_summary`、`ai_analysis` | `状态卡`、`Go_No-Go评分卡` |
| 数据来源与口径 | `metadata`、`raw_sources`、`workflow_trace` | `数据来源说明`、`调研边界`、`交互决策记录` |
| 候选方向与边界 | `metadata`、`constraints`、`normalized_tables.candidate` | `调研边界`、`产品路线矩阵`、`路线深挖计划` |
| 市场结构与数据质量 | `market_analysis`、`market_structure` | `市场结构`、`Top100原始明细`、`数据质量检查` |
| 关键词与需求信号 | `normalized_tables.candidate.demand_evidence`、`keyword_analysis` | `市场结构`、`数据来源说明` |
| 产品属性分布与交叉分析 | `market_structure.attribute_*`、`cross_analysis`、`opportunity_judgments` | `属性定义`、`Top商品打标`、`属性分布`、`属性交叉分析`、`机会判断`、`待确认标签` |
| 竞品池与竞品选择逻辑 | `competitor_selection_logic`、`competitor_pool`、`competitor_deep_dive` | `竞品选择逻辑`、`竞品池`、`竞品深拆卡` |
| 评论 VOC 与真实痛点 | `voc_analysis`、`normalized_tables.voc_evidence` | `评论VOC`、`VOC证据` |
| 利润复核 | `profit_reference`、`operator_inputs` | `利润测算输入`、`利润参考结果`、`利润成本拆分`、`供应链粗估` |
| 知产/合规/退货风险 | `return_risk`、`ip_screening`、`compliance_screening`、`ip_compliance_review` | `退货风险`、`知产合规复核`、`知产初筛`、`合规认证预判` |
| Go/Wait/No-Go 决策检查 | `decision_review`、`status_card` | `Go_No-Go评分卡`、`决策检查`、`风险矩阵`、`状态卡` |
| 下一步动作与证据附录 | `status_card`、`decision_review`、`workflow_trace` | `状态卡`、`交互决策记录` |

## 质量门槛

| 门槛 | 规则 |
|---|---|
| 摘要要有行动 | Executive Summary 不能只有数字，必须能读出下一步动作或待补项 |
| 表格后有洞察 | 关键数据表后必须有业务含义、风险或下一步，不只堆表 |
| 交叉分析要解释 | 机会判断必须区分 `真机会`、`伪机会`、`待验证`，并写下一步验证 |
| VOC 要能追溯 | 痛点必须能回到 `review_id`、ASIN、评分、原文片段 |
| 竞品要说明选择理由 | 竞品选择逻辑至少覆盖量级标杆、近半年新品、功能差异、价格带、痛点参考中的多类角色 |
| 评分卡受 gating 限制 | 利润或知产/合规未回填时，只能输出 Wait/观察/待补，不能强 Go |

## 校验入口

正式交付后必须运行：

```bash
python3 scripts/validate_research_outputs.py <workflow_output_dir>
```

校验器区分两类问题：

| 类型 | 含义 |
|---|---|
| error | 文件、章节、Sheet、评分卡、证据链等硬结构不满足，不能交付 |
| warning | 报告深度、竞品覆盖、分析模式痕迹等质量不足，需要人工审阅和补强 |
