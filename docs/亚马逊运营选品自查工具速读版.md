# 亚马逊运营选品自查工具速读版

更新日期：2026-06-07

## 先看定位

这套工具从模糊选品意图开始，先发现候选品池，再对重点候选生成主报告、摘要和看板。底层给自查和补数，上层只保留简洁结论和来源，不是让 AI 直接推荐爆品。

第一版先把一个选品意图转成候选品池，再把重点候选整理成运营能自查、能补数、能复盘的选品任务卡，帮助判断下一步是：

| 状态 | 含义 |
|---|---|
| 继续看 | 需求、竞品、利润和风险暂时说得通，可以进入报价、打样或 Listing 草案 |
| 试做 | 有机会，但关键假设还没验证，只做小范围验证 |
| 观察 | 有趋势或痛点，但证据不足，先放入观察清单 |
| 先放弃 | 利润、风险、退货、合规或差异化暂时不成立 |

如果团队更习惯“立项/试做/观察/淘汰”，可以把“继续看”映射成“立项”，把“先放弃”映射成“淘汰”。

## 双层输出

| 层级 | 给谁看 | 看什么 |
|---|---|---|
| 底层 | 运营 | 选品意图、候选品池、任务卡、竞品池、利润参考、退货风险、知产/合规、待补数据 |
| 上层 | 摘要与看板 | 报告摘要、关键结论、HTML 看板、简化版机会说明 |

同一套数据底座，既能支撑判断，也能直接生成报告和看板。所有强结论都要能追溯到来源，取不到就标待补，不硬猜。

## 运营怎么用

| 步骤 | 运营动作 | 工具动作 |
|---|---|---|
| 1 | 输入站点、禁区、偏好、大概方向 | 建立选品意图 |
| 2 | 等系统发现候选市场/关键词/产品方向 | 生成候选品池 |
| 3 | 复核候选方向是否相关 | 过滤不相关候选 |
| 4 | 对重点候选看 Top10 和近半年放量新品 | 生成竞品池卡片 |
| 5 | 候选进入继续看后再补采购价、头程、FBA、入库配置费等成本 | 生成利润参考卡片 |
| 6 | 看市场、利润、退货、知产、合规风险 | 给出继续看/试做/观察/先放弃的初判 |
| 7 | 修改判断、补证据、记录下一步 | 留下可复盘的选品记录 |

第一版不要求运营填一堆表。能自动取的数据先自动取，取不到的字段标记“待补”，运营只在关键位置复核。

## 第一版初始输入

第一步不要求运营先知道具体产品。

| 输入 | 是否必填 | 示例 |
|---|---|---|
| 站点 | 必填 | 美国站 |
| 大概方向 | 可选 | 户外、家居、宠物，也可以为空 |
| 明确禁区 | 必填 | 儿童、医疗、强认证、侵权、明显低价内卷等 |
| 偏好条件 | 可选 | 轻小、非强季节、10 美金以上 |
| 供应链优势 | 可选 | 五金、塑料、布艺、收纳、户外 |

可选快速勾选：

- 带电
- 带电池
- 带无线/蓝牙
- 儿童用品
- 食品接触
- 皮肤接触
- 医疗/健康宣称
- 激光/UV/加热/运动部件

售价区间、供应链报价、CPC 经验、退货率经验、图片/A+想法、材质和认证细节，都在候选品进入继续看/试做后再补。

价格带不做硬排除。报告里把类目平均售价分成 `10 美金以下` 和 `10 美金以上` 两组展示；`20-30 美金` 属于更有溢价空间的偏好区间，不写成系统规则。大件、太抛、仓储和头程压力太大的品，先做风险提示。

## 第一版工作台卡片

| 卡片 | 运营主要看什么 |
|---|---|
| 市场扫描卡 | 市场大不大、价格带是否合理、头部是否垄断、新品有没有机会 |
| 竞品池卡 | Top10 标杆组和近半年放量新品组是否选得准 |
| 利润参考卡 | 基础 FBA 毛利、扣广告和退货后的 FBA 毛利是否还能接受 |
| 退货风险卡 | 类目退货率、评论中的结构性问题是否需要谨慎 |
| 知产/合规卡 | 专利、商标、版权、认证是否有明显早期风险 |
| 待补数据卡 | 哪些字段还缺，哪些判断需要运营补经验 |
| 下一步卡 | 继续看、试做、观察、先放弃，以及对应动作 |

Excel 数据表作为底层证据源和复核底表，MD 报告和 HTML 看板作为上层阅读界面。

## 利润只是参考值

利润测算不是替运营最终核算，只是帮助早期判断“这个方向值不值得继续看”。

| 层级 | 口径 |
|---|---|
| 基础 FBA 毛利 | 建议售价 - 采购价 - 头程 - FBA 费用 - 佣金 - 仓储费 - 入库配置费 |
| 扣广告和退货后的 FBA 毛利 | 基础 FBA 毛利 - 新品广告费 - 预估退款损失 |

最低字段：

| 字段 | 默认口径 |
|---|---|
| 建议售价 | 运营可填，也可先按竞品价格带估算 |
| 采购价 | 运营或供应链填写 |
| 站点汇率 | 按调研时点汇率 |
| 实际重量/体积重 | 运营手填 |
| 预估头程费用 | 系统按计费重和渠道单价估算，运营可改 |
| FBA 费用 | 运营手填，以亚马逊后台/收入计算器为准 |
| 佣金率 | 先按 15%，实际以 Amazon 后台费率表为准 |
| 仓储费 | 早期统一按建议售价 3% 简化估算 |
| 入库配置费 | 运营手填；不确定先标记待补，不默认 0 |
| 新品广告费率 | 默认 20%，运营可按实际经验调整 |
| 退货率 | 先按类目平均值，来源必须标注 |

每一层都给毛利额和毛利率。运营通常会把售价、采购价、头程、FBA、佣金、仓储、入库、广告、退货一起预估完，再决定是否继续调研。利润只做参考，不替最终核算。

头程费用按 `计费重(g) / 1000 * 渠道单价` 估算，计费重取体积重和实际重的较大值。当前经验单价：美国美森 11 元/kg、美国普船 6 元/kg、加拿大尊享达 22 元/kg、加拿大海卡 9 元/kg；美国美森约等于加拿大尊享达，美国普船约等于加拿大海卡。

CPC 如果来自卖家精灵关键词建议竞价，只作为广告竞争参考，不等于广告后台真实 CPC。

## 退货率怎么用

退货率是风险提示，不是自动淘汰按钮。

| 情况 | 处理 |
|---|---|
| 细分类目退货率长期明显高于平均 | 标高风险，提醒运营谨慎 |
| 评论反复提到硬伤且业内长期难解决 | 标结构性问题线索，优先看有没有明确改品方案 |
| 有明确改品方案 | 可以进入试做，但要写清验证点 |
| 没有退货率数据 | 先用类目平均值，并标记待复核 |

这里的“硬伤”不是普通差评，而是类似高空玻璃磁吸清洁器这类长期需求很大、但核心问题很难彻底解决的品。第一版只把它当结构性风险提示，不写成强制淘汰规则，避免选品阶段设限过死。

如果某个细分类目的退货率明显高于类目平均，或者长期在 `10%` 左右及以上，通常就要标高风险；这只是参考线，不是硬阈值。运营一般更偏好接近类目平均、最好低于 `10%` 的品。

退货率来源必须标注：第三方工具估算值、运营经验值、自有后台数据，还是暂用类目平均值。自有后台数据只能代表自有产品，不当作全类目精确值。

## 竞品怎么选

| 竞品组 | 用途 |
|---|---|
| Top10 标杆组 | 看市场天花板、价格带、头部卖点、评论门槛 |
| 近半年放量新品组 | 看新品怎么起量、怎么做内容、怎么切关键词 |
| 结构补充组 | 补低价、高价、高评分、差评集中、不同功能路线样本 |

“近半年放量新品”默认优先看：近半年上架，且 BSR 进入小类前 100，或月销量达到 Top100 月销量中位数 20% 以上。阈值可以按品类调整。

## 评论插件怎么接入

第一版不强制采集评论。只有当竞品池确认值得深挖时，再用现有评论采集插件采 3-5 个核心 ASIN。

| 插件产物 | 用法 |
|---|---|
| Excel 评论明细 | 系统分析主输入，保留评论 ID、评分、Helpful、链接、原文和译文 |
| HTML AI 分析报告 | 运营快速阅读痛点、亮点、改品建议，不替代 Excel 证据链 |

也就是说，插件会接入整套工具，但放在深挖阶段，不压到第一版初筛里。

## 第一版不做什么

| 不做 | 原因 |
|---|---|
| 不替运营做最终决定 | 运营要结合供应链、预算、经验和团队能力判断 |
| 不替代利润核算 | 早期利润只做参考，运营通常会重新核算 |
| 不替代律师/检测机构 | 专利和合规只做初筛 |
| 不强制做深度评论 | 评论深挖只在值得继续时启动 |
| 不先做图片/A+和推广节奏 | 第一版先判断能不能继续看，深挖后再做内容和推广 |
| 不只做底层材料 | 底层必须保留可复核的数据和判断过程 |
| 不硬猜不确定项 | 关键信息不确定就暂停，先让运营补数据再继续 |

## 建议运营先评审 6 个问题

1. 4 个必填输入够不够启动一次初筛？
2. 工作台卡片是否贴近日常选品习惯？
3. Top10 标杆组 + 近半年放量新品组，是否符合你们选竞品方式？
4. 利润参考字段是否够用，哪些字段希望手填？
5. 退货率和结构性问题只做风险提示，这个边界是否合适？
6. 深挖阶段再接入评论插件，是否符合实际工作节奏？
7. 报告摘要要不要固定成一页，写得更简洁一点？
