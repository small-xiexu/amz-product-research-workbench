# 静态报告 Mock

更新日期：2026-06-07

## 目标

先把 V1 的最终输出样式定住，后续再把真实数据填进去。

## 输出结构

单次调研固定输出 4 份内容：

1. `report.md` 主报告
2. `summary.md` 摘要
3. `dashboard.html` 看板
4. `data.xlsx` 数据底表

## 主报告结构

```text
# 调研标题
## 结论摘要
## 市场扫描
## Top100 属性打标
## 属性交叉分析
## 竞品池
## 关键词与趋势
## 利润参考
## 退货风险
## 知产初筛
## 合规初筛
## 状态判断
## 下一步
## 数据来源
```

## 主报告样式示例

```md
# outdoor camping lantern 调研报告

## 结论摘要
- 市场有需求，价格带集中在中低价位，仍有溢价空间。
- Top10 竞品结构清晰，近半年新品有放量机会。
- 利润参考可接受，但 FBA、头程和广告需要手填校准。
- 退货率和合规风险需要人工复核后再定状态。

## 市场扫描
| 指标 | 结果 | 说明 |
|---|---|---|
| 市场规模 | 待填 | 来自卖家精灵 MCP |
| 价格带 | 待填 | 10 美金以下 / 10 美金以上分组 |
| 品牌集中度 | 待填 | 识别是否头部垄断 |
| 新品占比 | 待填 | 识别新品机会 |
```

## 摘要样式示例

```md
# 摘要

- 这个市场值不值得继续看：待填
- 最大机会点：待填
- 最大风险点：待填
- 下一步：待填
```

## 看板样式

看板不写长文，只保留可扫读信息：

| 区块 | 内容 |
|---|---|
| KPI 卡 | 市场规模、价格带、集中度、新品占比、利润参考 |
| 竞品卡 | Top10、近半年放量新品、结构补充组 |
| 风险卡 | 退货、知产、合规、结构性问题 |
| 机会卡 | 值得继续看、试做、观察、先放弃 |
| 来源卡 | MCP、手填、系统计算、人工复核 |

## 数据底表样式

Excel 至少包含这些 Sheet：

- 数据来源说明
- 调研边界
- 运营手填项
- 市场结构
- Top100 原始明细
- 数据质量检查
- 属性维度定义
- Top100 属性打标
- 属性交叉分析
- 竞品池
- 利润测算输入
- 利润参考结果
- 退货风险
- 知产初筛
- 合规认证预判
- 状态卡

## 占位规则

1. 所有待确认项统一写“待填”。
2. 不允许用模糊词替代来源。
3. 报告里每个结论都要能回到 `data.xlsx` 或 `research_package.json`。
4. 摘要必须能在 30 秒内看完。
5. 看板必须能在 10 秒内扫到结论。
