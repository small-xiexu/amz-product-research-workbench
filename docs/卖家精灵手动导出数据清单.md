# 卖家精灵手动导出数据清单

更新日期：2026-06-10

## 目标

V1 不依赖卖家精灵 MCP。AI 根据选品意图生成数据采集清单，用户按清单从卖家精灵手动导出 Excel/CSV 或整理表，再交给系统分析。后续自动化只考虑 MCP，不再规划 HTTP API 接入。

这条路线优先服务低成本试跑：

`选品意图/市场大盘 -> AI 生成导出清单 -> 用户导出卖家精灵数据 -> 系统校验字段 -> 缺什么补什么 -> 候选品池 -> 深挖报告`

## 两种导出模式

| 模式 | 第一轮导出 | 是否需要关键词 | 用途 |
|---|---|---|---|
| 无方向探索 | 卖家精灵 `选市场 200 条` | 不需要 | 从 200 个细分市场里筛 3-5 个候选方向 |
| 指定方向深挖 | 市场分析、搜索结果/Top100、关键词/ABA | 需要 2-3 个精准主关键词 | 验证某个方向是否值得继续看 |

无方向探索先不导关键词表，也不要求运营硬想关键词。系统先用 `选市场 200 条` 看市场容量、集中度、新品占比、退货率、重量体积、毛利率和搜索购买比，再建议下一轮要深挖的方向。

## 指定方向关键词策略

第一轮导出不要铺太多关键词，优先使用 2-3 个最精准的锚词。

规则：

- 先用最贴近产品形态的核心词
- 如果结果太少，再补 1-2 个同义词或场景词
- 不要把扩展词、场景词、功能词一次全塞进去
- 第一轮目标是拿到干净的市场轮廓，不是一次性把所有相近词都跑完

## 推荐落盘位置

卖家精灵导出的原始文件，建议放在项目根目录下的独立文件夹里，和代码目录并列，不要混进 `docs/`、`scripts/` 或 `packages/`。

推荐结构示例：

```text
/Users/sxie/Documents/亚马逊/amz-product-research-workbench/
  卖家精灵导出_刮窗器_20260608/
    Search(...).xlsx
    US-Market-....xlsx
    ReverseASIN-....xlsx
    ABA-....xlsx
```

同一轮导出的相关文件尽量放在同一个文件夹，后续工作流直接传这个文件夹路径即可。

## 数据来源优先级

| 优先级 | 来源 | 用法 |
|---|---|---|
| 1 | 卖家精灵手动导出 Excel/CSV | V1 主路线 |
| 2 | 卖家精灵页面复制表格或截图补充 | 没有导出入口时兜底 |
| 3 | 卖家精灵 MCP | 后续预算允许后接 Agent 自动调用 |

## V1 最小数据包

没有 MCP 时，数据包按模式拆开，不再要求所有场景一开始都导全。

### 无方向探索最小包

| 数据包 | 卖家精灵功能 | 最小用途 | 优先级 |
|---|---|---|---|
| 市场大盘表 | 选市场，导出前 200 条 | 找候选市场/类目方向、排除明显不适合的市场 | 必需 |
| 运营边界 | 人工填写 | 站点、禁区、偏好、供应链限制，用来过滤 AI 不该推荐的方向 | 必需 |

无方向探索第一轮只输出候选方向，不输出最终选品结论。

### 指定方向深挖最小包

方向已确认后，先拿到下面 3 类数据即可开始真实初筛。

| 数据包 | 卖家精灵功能 | 最小用途 | 优先级 |
|---|---|---|---|
| 产品候选表 | 选产品/产品调研 | 找候选产品方向、价格带、销量、评论门槛、上架时间 | 必需 |
| 关键词表 | 关键词选品、关键词挖掘、关键词反查 | 判断需求、流量入口、趋势和广告竞争参考 | 必需 |
| 竞品表 | 查竞品、ASIN 列表、Top10/新品 ASIN 明细 | 生成竞品池、识别标杆组和近半年新品组 | 必需 |
| 市场结构表 | 选市场、市场统计、集中度、价格/评分/上架分布 | 判断市场容量、集中度、生命周期 | 推荐 |
| 趋势表 | Keepa、销量趋势、优惠趋势、Google 趋势 | 判断季节性、促销依赖和价格稳定性 | 推荐 |
| 商标表 | 全球商标库列表/详情 | 商标初筛 | 可选 |

## 当前已支持的样例文件类型

基于 `卖家精灵导出样例_美国站_宠物牵引绳_20260607`，第一版导入盘点脚本已经能识别：

| 文件类型 | 自动识别值 | 说明 |
|---|---|---|
| 卖家精灵搜索结果/产品调研表 | `seller_sprite_search_results` | 识别产品候选、品牌汇总、卖家汇总 |
| 卖家精灵市场分析表 | `seller_sprite_market_analysis` | 识别市场概况、趋势、集中度、退货率、价格/评分/上架分布 |
| 卖家精灵关键词反查表 | `seller_sprite_reverse_asin_keywords` | 识别流量词、自然/广告排名、搜索量、PPC、前十 ASIN |
| Amazon ABA 关键词表 | `amazon_aba_keywords` | 识别搜索频率排名、点击品牌、点击 ASIN、点击/转化份额 |

盘点命令：

```bash
python3 scripts/inspect_manual_exports.py <导出文件夹> <输出manifest.json> --site US --task-name <任务名>
```

输出的 `import_manifest.json` 只记录文件结构、字段和缺失项，不把原始卖家精灵导出文件提交到仓库。

生成候选品池：

```bash
python3 scripts/build_candidate_pool_from_import_manifest.py <manifest.json> <candidate_pool.json>
```

第一版候选池会把市场分析、产品结果、关键词反查和 ABA 关键词整合成一个候选方向，输出需求证据、竞争结构、新品机会、退货风险、缺失数据和下一步动作。

生成候选品池预审输出：

```bash
python3 scripts/build_candidate_pool_precheck.py <candidate_pool.json> <输出目录>
```

预审输出用于进入评论/VOC 深挖前的人工判断，不替代正式选品报告。输出内容包括：

- `precheck_report.md`：候选方向、证据、风险、缺失数据和下一步。
- `precheck_summary.md`：快速摘要。
- `precheck_dashboard.html`：可打开查看的候选池看板。
- `precheck_data.xlsx`：候选总览、详情、缺失数据和来源追溯底表。

## 用户导出规则

| 项 | 规则 |
|---|---|
| 文件格式 | 优先 Excel，其次 CSV |
| 文件命名 | `站点_功能_关键词或类目_日期.xlsx` |
| 文件保留 | 原始导出不要改名覆盖，后续清洗另存 |
| 筛选条件 | 导出时记录站点、关键词、类目、价格带、评分、上架时间等筛选条件 |
| 来源说明 | 每份文件配一行来源说明：卖家精灵功能、导出时间、站点、筛选条件 |
| 缺字段处理 | 系统校验后再让用户补导，不让 AI 猜 |

## 产品候选表字段

产品候选表用来生成候选品池，是最重要的数据。

| 字段 | 用途 |
|---|---|
| ASIN/父 ASIN | 去重、追溯、竞品深挖 |
| 标题 | 产品形态识别、属性打标 |
| 类目路径/节点 | 市场边界判断 |
| 品牌/卖家 | 集中度和卖家画像 |
| 价格 | 价格带、利润空间粗判 |
| 月销量/月销售额 | 需求和市场规模 |
| BSR/排名 | 销量反证和趋势判断 |
| 评分值/评分数 | 评论门槛、满意度、进入难度 |
| 上架时间 | 新品机会、生命周期 |
| FBA/FBM/AMZ | 配送结构 |
| 尺寸/重量/FBA 费用 | 利润复核前的粗略可行性 |
| 变体数 | 多 SKU 统计口径 |
| LQS/A+/视频/图片数 | Listing 质量和内容门槛 |

## 关键词表字段

关键词表用来判断需求是不是成立。

| 字段 | 用途 |
|---|---|
| 关键词 | 需求入口 |
| 搜索量 | 需求大小 |
| 搜索趋势 | 淡旺季和增长 |
| 竞争商品数 | 竞争强度 |
| 点击集中度/转化相关字段 | 流量是否被头部垄断 |
| 建议竞价/CPC 参考 | 广告竞争参考，不等于后台真实 CPC |
| 关联 ASIN/流量 ASIN | 竞品池补充 |
| 自然排名/广告排名 | 流量结构判断 |

## 竞品表字段

竞品表用于构建三组竞品池。

| 组 | 需要的数据 |
|---|---|
| Top10 标杆组 | 当前销量/排名靠前 ASIN |
| 近半年放量新品组 | 近半年上架且有一定销量的 ASIN |
| 结构补充组 | 低价、高价、高评分、差评集中、不同功能路线 ASIN |

必需字段：

- ASIN
- 标题
- 价格
- 月销量/月销售额
- BSR/排名
- 评分值/评分数
- 上架时间
- 品牌/卖家
- 类目路径

## 市场结构表字段

市场结构表不是第一步强制，但会显著提升报告质量。

| 字段/图表 | 用途 |
|---|---|
| 市场规模/销量/销售额 | 判断容量 |
| 商品集中度 | 判断头部垄断 |
| 品牌集中度 | 判断品牌壁垒 |
| 卖家集中度/卖家所属地 | 判断进入难度 |
| 价格分布 | 找价格带和价格真空 |
| 评分值/评分数分布 | 判断评论门槛 |
| 上架时间/上架趋势 | 判断新品机会 |
| 商品需求趋势 | 判断生命周期 |

如果卖家精灵页面不能导出，可先截图或复制表格，系统只写弱结论。

## AI 和用户交互方式

1. 用户只输入站点、禁区、大概方向和偏好。
2. AI 生成本次导出清单。
3. 用户按清单导出卖家精灵数据。
4. 系统读取文件并做字段校验。
5. 系统输出缺失字段清单。
6. AI 只要求用户补最关键的数据，不一次性要太多。
7. 数据足够后，系统生成候选品池和报告。

## 验收标准

- 系统能说明每个候选方向来自哪份导出文件。
- 缺少关键字段时，不生成强结论。
- 手动导入和未来 MCP 返回的数据都要转成同一套标准字段。
- 后续接 MCP 时，只替换数据采集层，不重写选品分析逻辑。
