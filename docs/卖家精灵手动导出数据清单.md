# 卖家精灵手动导出数据清单

更新日期：2026-06-07

## 目标

V1 不依赖卖家精灵 API 或 MCP。AI 根据选品意图生成数据采集清单，用户按清单从卖家精灵手动导出 Excel/CSV 或整理表，再交给系统分析。

这条路线优先服务低成本试跑：

`选品意图 -> AI 生成导出清单 -> 用户导出卖家精灵数据 -> 系统校验字段 -> 缺什么补什么 -> 候选品池 -> 深挖报告`

## 数据来源优先级

| 优先级 | 来源 | 用法 |
|---|---|---|
| 1 | 卖家精灵手动导出 Excel/CSV | V1 主路线 |
| 2 | 卖家精灵页面复制表格或截图补充 | 没有导出入口时兜底 |
| 3 | 卖家精灵 HTTP API | 后续预算允许后自动化 |
| 4 | 卖家精灵 MCP | 后续预算允许后接 Agent 自动调用 |

## V1 最小数据包

没有 API/MCP 时，先拿到下面 3 类数据即可开始真实初筛。

| 数据包 | 卖家精灵功能 | 最小用途 | 优先级 |
|---|---|---|---|
| 产品候选表 | 选产品/产品调研 | 找候选产品方向、价格带、销量、评论门槛、上架时间 | 必需 |
| 关键词表 | 关键词选品、关键词挖掘、关键词反查 | 判断需求、流量入口、趋势和广告竞争参考 | 必需 |
| 竞品表 | 查竞品、ASIN 列表、Top10/新品 ASIN 明细 | 生成竞品池、识别标杆组和近半年新品组 | 必需 |
| 市场结构表 | 选市场、市场统计、集中度、价格/评分/上架分布 | 判断市场容量、集中度、生命周期 | 推荐 |
| 趋势表 | Keepa、销量趋势、优惠趋势、Google 趋势 | 判断季节性、促销依赖和价格稳定性 | 推荐 |
| 商标表 | 全球商标库列表/详情 | 商标初筛 | 可选 |

## 用户导出规则

| 项 | 规则 |
|---|---|
| 文件格式 | 优先 Excel，其次 CSV |
| 文件命名 | `站点_功能_关键词或类目_日期.xlsx` |
| 文件保留 | 原始导出不要改名覆盖，后续清洗另存 |
| 筛选条件 | 导出时记录站点、关键词、类目、价格带、评分、上架时间等筛选条件 |
| 来源说明 | 每份文件配一行来源说明：卖家精灵功能、导出时间、站点、筛选条件 |
| 缺字段处理 | 系统校验后再让用户补导，不让 AI 猜 |

## 产品候选表字段

产品候选表用来生成候选品池，是最重要的数据。

| 字段 | 用途 |
|---|---|
| ASIN/父 ASIN | 去重、追溯、竞品深挖 |
| 标题 | 产品形态识别、属性打标 |
| 类目路径/节点 | 市场边界判断 |
| 品牌/卖家 | 集中度和卖家画像 |
| 价格 | 价格带、利润空间粗判 |
| 月销量/月销售额 | 需求和市场规模 |
| BSR/排名 | 销量反证和趋势判断 |
| 评分值/评分数 | 评论门槛、满意度、进入难度 |
| 上架时间 | 新品机会、生命周期 |
| FBA/FBM/AMZ | 配送结构 |
| 尺寸/重量/FBA 费用 | 利润复核前的粗略可行性 |
| 变体数 | 多 SKU 统计口径 |
| LQS/A+/视频/图片数 | Listing 质量和内容门槛 |

## 关键词表字段

关键词表用来判断需求是不是成立。

| 字段 | 用途 |
|---|---|
| 关键词 | 需求入口 |
| 搜索量 | 需求大小 |
| 搜索趋势 | 淡旺季和增长 |
| 竞争商品数 | 竞争强度 |
| 点击集中度/转化相关字段 | 流量是否被头部垄断 |
| 建议竞价/CPC 参考 | 广告竞争参考，不等于后台真实 CPC |
| 关联 ASIN/流量 ASIN | 竞品池补充 |
| 自然排名/广告排名 | 流量结构判断 |

## 竞品表字段

竞品表用于构建三组竞品池。

| 组 | 需要的数据 |
|---|---|
| Top10 标杆组 | 当前销量/排名靠前 ASIN |
| 近半年放量新品组 | 近半年上架且有一定销量的 ASIN |
| 结构补充组 | 低价、高价、高评分、差评集中、不同功能路线 ASIN |

必需字段：

- ASIN
- 标题
- 价格
- 月销量/月销售额
- BSR/排名
- 评分值/评分数
- 上架时间
- 品牌/卖家
- 类目路径

## 市场结构表字段

市场结构表不是第一步强制，但会显著提升报告质量。

| 字段/图表 | 用途 |
|---|---|
| 市场规模/销量/销售额 | 判断容量 |
| 商品集中度 | 判断头部垄断 |
| 品牌集中度 | 判断品牌壁垒 |
| 卖家集中度/卖家所属地 | 判断进入难度 |
| 价格分布 | 找价格带和价格真空 |
| 评分值/评分数分布 | 判断评论门槛 |
| 上架时间/上架趋势 | 判断新品机会 |
| 商品需求趋势 | 判断生命周期 |

如果卖家精灵页面不能导出，可先截图或复制表格，系统只写弱结论。

## AI 和用户交互方式

1. 用户只输入站点、禁区、大概方向和偏好。
2. AI 生成本次导出清单。
3. 用户按清单导出卖家精灵数据。
4. 系统读取文件并做字段校验。
5. 系统输出缺失字段清单。
6. AI 只要求用户补最关键的数据，不一次性要太多。
7. 数据足够后，系统生成候选品池和报告。

## 验收标准

- 系统能说明每个候选方向来自哪份导出文件。
- 缺少关键字段时，不生成强结论。
- 手动导入和未来 API/MCP 返回的数据都要转成同一套标准字段。
- 后续接 API/MCP 时，只替换数据采集层，不重写选品分析逻辑。
